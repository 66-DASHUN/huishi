# 绘世首页与重点界面优化设计规格

日期：2026-07-15

状态：范围已确认

设计决策方式：Claude 主导产品与视觉判断，Codex 负责核验现有功能、主题边界和实现风险

## 1 范围

本次只修改五个明确区域：

1. 首页 Hero 与创作流程双视频页面
2. 画布项目卡片
3. 画布底部缩放 HUD 与主工具栏
4. 工作区左下设置菜单
5. 全部管理后台页面

首页在自己的 React 与 Tailwind 资源中独立设计。首页视觉不作为全局主题，不覆盖登录后的工作台、画布或管理后台。

## 2 非目标

- 不把首页样式写入 `static/css/site.css`
- 不把首页字体、视频、玻璃或大标题规则扩散到工具页面
- 不改变生成、计费、权限、路由、数据模型和 iframe 通信协议
- 不修改无限画布节点编辑、Agent 对话或生成逻辑
- 不宣传当前不存在的图层、版本管理或续画能力

## 3 首页

### 3.1 技术边界

首页继续使用：

- `templates/home.html`
- `static/js/home.js`
- `static/css/home-tailwind.input.css`
- `static/js/home.compiled.js`
- `static/css/home-tailwind.css`

首页不加载 `static/css/site.css`。构建继续使用现有 esbuild 与 Tailwind 脚本。

展示性文案不使用标点符号。输入校验、日期、尺寸和错误信息保留必要符号。

### 3.6 视频循环

两个视频共用 `FadingVideo`：

- 禁止原生 `loop`
- `FADE_MS = 500`
- `FADE_OUT_LEAD = 0.55`
- 通过 `requestAnimationFrame` 修改内联 `opacity`
- 新淡入或淡出前取消前一个 rAF
- `loadeddata` 时从 0 淡入到 1
- `timeupdate` 在结束前淡出
- `ended` 时保持透明，100ms 后重置并重播
- 卸载时移除监听器、取消 rAF 与定时器
- 不对视频使用 CSS Transition
- `prefers-reduced-motion` 下停止自动循环并显示 Poster

## 4 画布项目卡片

当前硬编码 `#f1eee8`、`stone-*` 和 16px 圆角，与画布主题不一致。

卡片改为读取现有 `canvasThemes` 与 Tailwind 语义 Token：

- 浅色页面 `#f8f9fb`
- 浅色卡片 `#ffffff`
- 浅色边框 `#e2e6ec`
- 深色页面 `#111317`
- 深色卡片 `#1a1e24`
- 深色边框 `#343a45`

卡片规则：

- 圆角 8px
- 取消固定最小高度
- 结构为标题、节点与连线、更新时间、操作
- Hover 只增强边框和轻微阴影，不切换到另一套底色
- 复选框在 Hover、键盘聚焦、选中或批量状态下显示
- 导出、重命名和删除使用 Lucide 图标、Tooltip 与 `aria-label`
- 删除与其他操作视觉分隔并使用危险色
- 卡片点击仍进入画布，操作区继续阻止冒泡

## 5 画布底部 Rail

当前缩放 HUD 固定左下，主工具栏独立居中。Agent 打开后画布变窄，两者没有碰撞规则，导致重叠或贴合。

桌面端保持两个 Dock，但放进同一条画布内 Rail：

- Rail 位于画布 Section 内部
- `inset-inline: 16px`
- `bottom: 16px`
- 缩放 HUD 位于左列
- 主工具栏位于剩余空间并居中
- 两者统一高 48px、圆角 8px和同一主题 Token
- Agent 打开时 Rail 随画布自动变窄
- 不使用 JS 测量碰撞
- 不允许工具栏伸入 Agent 面板

主工具栏分组：

- 移动、撤销、重做
- 文本、图片、视频、音频
- 生成配置
- 上传、素材库
- 助手、画布外观
- 清空画布

窄桌面时允许主工具栏内部水平滚动，不能覆盖缩放 HUD。小于 640px 时继续使用现有移动端工具栏。

## 6 设置菜单

设置菜单宽度由 138px 调整为约 228px。取消主题二级弹出菜单，改为菜单内三段控制。

分组：

1. 账户、充值
2. 主题：浅色、深色、系统
3. 管理后台，仅管理员渲染
4. 退出登录

规则：

- 每项使用图标和文字
- 主题按钮使用 `aria-pressed`
- 管理后台使用盾牌图标并单独分组
- 退出登录独立分隔并使用危险色
- 菜单根据可用空间向右上或左上展开
- 所有文字完整显示

## 7 管理后台

### 7.1 根因修复

后台当前同时使用 `console-page` 与 `admin-console-page`。旧 `.console-page` 规则仍注入 `--c-*`、深色文字和 `Instrument Serif`，后面的样式再用大量 `!important` 局部覆盖，造成不同页面文字不可见与风格漂移。

修复方式：

- 后台 Body 只保留 `admin-console-page`
- 后台全部使用 `Noto Sans SC`
- 后台不读取 `Instrument Serif` 和旧 `--c-*`
- 所有文字只从 `--admin-ink` 与 `--admin-muted` 获取
- 所有表面只从 `--admin-canvas`、`--admin-surface` 与 `--admin-soft` 获取
- 不再依赖针对单页添加的深色文字补丁

### 7.2 统一界面

- 左侧导航保持 232px，当前项使用明确强调线和语义主色
- 顶部保留环境、管理员身份和返回工作台
- 标题最大 28px，不使用营销式大标题
- 核心指标使用扁平统计带
- 表格统一紧凑行高、Sticky 表头和语义状态
- 数值列右对齐并使用等宽数字
- 筛选位于表格上方
- 批量操作保留权限与确认逻辑
- 用户编辑继续使用右侧抽屉
- 健康状态使用状态点与文字
- 配置表单统一标签、说明和控件宽度
- 小于 760px 时导航收进可访问抽屉，表格显示关键列并保留详情入口

## 8 样式隔离

- 首页样式只存在于 `home-tailwind.input.css`
- 画布样式优先使用组件 Tailwind 类和 `canvasThemes`
- 设置与管理后台规则限定在 `.workspace-page .rail-settings-panel` 和 `.admin-console-page`
- 不新增裸标签全局规则
- 不更改首页使用的按钮、标题或卡片基类

## 9 验收标准

1. 首页只加载首页 CSS，不加载 `site.css`
2. 首页两段视频来源正确，第二屏不复用首页视频
3. 两段视频无原生 `loop` 且使用 rAF 淡出重播
4. 首页真实输入在认证跳转后不丢失且不进入 URL
5. 首页展示文案不含标点符号
6. 画布卡片不存在 `#f1eee8` 与 `stone-*` 颜色类
7. 画布卡片在深浅主题下使用语义表面、边框与文字色
8. Agent 开关两种状态下底部两个 Dock 零重叠
9. 底部两个 Dock 同高、同底部偏移且不伸入 Agent 面板
10. 设置菜单中“跟随系统”不截断，三态切换即时生效并持久化
11. 管理后台 Body 不再包含 `console-page`
12. 管理后台不出现 `Instrument Serif` 与旧 `--c-*` 依赖
13. 管理后台所有页面在深浅主题下正文对比度达到 WCAG AA
14. 权限、生成、计费、删除确认、批量操作和路由行为保持不变
15. `360x800`、`768x1024`、`1440x900` 与 `1920x1080` 下无文字重叠和无意横向溢出
