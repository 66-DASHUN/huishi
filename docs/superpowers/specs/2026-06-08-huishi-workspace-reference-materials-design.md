# 绘世工作台参考素材与计费基准设计

日期：2026-06-08

## 背景

当前项目已有 Flask 后端、Vite/React 首页、Jinja 工作台模板、生成记录、积分计费和后台管理能力。现有测试中仍保留旧产品形态的断言，例如首页资产入口、后台入口、登录后自动进入工作台、显式参考图上传/图生图模式等。这些不再代表当前产品方向。

本轮目标是以当前首页视觉和文案为基准，修正登录流、工作台参考素材交互、分辨率计费和测试验收标准。除必要交互状态外，不重构首页视觉和文案。

## 产品基准

首页保持当前视觉和按钮文案。未登录用户点击“开始创作”时打开登录/注册弹窗。登录或注册成功后留在首页，只刷新登录态，例如右上角显示用户名。登录后用户可以自行点击“开始创作”进入 `/workspace`，或点击“充值”进入 `/pricing`。

首页不新增导航入口，不恢复资产入口，不暴露后台入口。后台能力保留，管理员仍可直接访问 `/admin/`。

工作台不展示“参考图上传”“图生图”等模式入口。参考图片作为自然创作素材存在：用户可以点击输入区左侧的加号添加本地图片，也可以把本地文件或已生成图片拖到工作台。添加后，素材缩略图在输入区左侧叠放显示。

生成始终使用同一个按钮和同一个表单。没有参考素材时是纯文本生成；存在参考素材时，请求自动携带参考素材。用户不需要切换模式。

## 首页登录流

未登录时：

- 品牌、当前首页内容、按钮视觉保持现状。
- 点击“开始创作”打开登录/注册弹窗，而不是直接跳转工作台。
- 点击“充值”按现有逻辑进入充值页；如果充值页需要登录，由后端现有权限逻辑处理。

登录或注册成功后：

- 用户仍停留在首页。
- 前端刷新 `/api/session` 状态。
- 首页显示登录态，例如右上角用户名。
- 用户再次点击“开始创作”时进入 `/workspace`。

不新增“工作台 / 账户 / 充值”导航，不恢复“资产 / 管理后台”首页入口。

## 工作台参考素材交互

输入区左侧增加参考素材栈组件。组件状态如下：

- 空状态：显示一个轻量的倾斜加号卡片。
- 有素材：缩略图叠放显示，并保留加号入口。
- 桌面端：鼠标悬停素材栈时展开为横向缩略图列表。
- 移动端：点击素材栈先展开，再点击单张图片放大。
- 展开态：可继续点击加号添加图片，可删除单张素材。
- 预览态：点击单张缩略图打开放大预览，支持关闭。

添加素材的方式：

- 点击加号选择本地图片。
- 将本地图片文件拖到工作台任意有效区域。
- 将页面中的已生成图片拖到工作台任意有效区域。

拖入工作台不要求用户精准拖到素材栈位置。拖入时可以显示轻量提示，表示松手后会添加为参考素材。弹窗、明显不可交互遮罩、浏览器默认文件打开行为不应截获有效拖入。

支持多张参考素材。具体数量上限沿用后端配置 `MAX_REFERENCE_IMAGES`，超过上限时提示用户删除部分素材后再添加。

## 参考素材保存

本地文件素材在生成前只保存在浏览器内存中，用于临时预览。用户点击生成时，本地文件随生成请求上传，后端保存文件并把路径写入本次作品记录。

已生成图片作为参考素材时，不重复上传也不复制文件。记录只保存原图片路径引用。

作品记录需要保存生成时使用的参考素材路径。以后“再次生成 / 继续编辑”该记录时，工作台自动恢复当时的参考素材到素材栈。

资产删除采用隐藏/软删除策略。用户从资产列表删除图片后，该图片从列表消失，但底层文件和历史记录引用保留，以保证历史生成记录仍可复用参考素材。

## 分辨率与计费

计费按最终输出尺寸的最长边归档为 1K / 2K / 4K。文生和带参考素材生成同档同价，参考素材数量不改变单张生成单价。

默认档位阈值集中配置，初始规则为：

- 最长边 `<= 1560`：1K
- 最长边 `1561 - 2440`：2K
- 最长边 `2441 - 4280`：4K
- 超出 4K 上限：不允许生成，提示降低分辨率

用户可以使用预设比例快捷项，也可以手动输入宽高。用户手动修改宽高后，取消比例选中并显示“自定义”。最终生成尺寸以手动宽高为准。

自定义尺寸必须符合模型/API 支持范围。不支持时，系统提示并推荐最近可用尺寸；只有用户确认后才替换输入值。后端在生成请求时仍需做最终校验，防止绕过前端限制。

工作台界面只显示 `X 点`，不写“预计消耗”，也不展示档位说明。宽高输入框失焦后更新点数；输入过程中不强制实时更新。积分不足时生成按钮禁用，并在按钮附近显示“积分不足”。

## 后端数据与接口

生成接口继续作为统一入口。前端提交时包含：

- 提示词
- 输出宽高
- 数量、质量、格式等现有参数
- 本地参考素材文件列表
- 已生成图片参考路径列表

后端根据是否存在参考素材决定调用文本生成或编辑/参考生成能力，但这个模式判断不暴露给用户界面。

作品记录保留或扩展 `reference_paths` 字段，用于保存本次生成实际使用的参考素材路径。路径可以来自新上传文件，也可以来自已有生成图。

计费逻辑集中在 `huishi.billing`。需要提供按宽高最长边解析档位和计算点数的函数，所有生成路径都使用同一套后端计费函数。

资产删除需要从硬删除改为软删除或列表隐藏。列表查询默认排除隐藏资产，历史记录和引用文件仍可访问。

## 前端结构

首页 React 仅调整登录表单提交后的状态处理和“开始创作”未登录行为。视觉和文案不做重构。

工作台模板负责提供素材栈容器、文件输入、预览弹窗容器和必要的数据属性。`static/js/workspace.js` 负责：

- 素材栈状态管理
- 文件选择
- 拖拽进入、悬停提示、释放添加
- 已生成图片拖回工作台
- 缩略图叠放、展开、删除、放大
- 生成请求 `FormData` 组装
- 宽高失焦后的点数刷新
- 尺寸不支持时的推荐尺寸提示

生成图卡片需要带可拖拽数据，例如图片路径、记录 id 或必要参数。拖动生成图到工作台时，前端把路径加入参考素材列表，而不是重新上传文件。

## 错误处理

添加非图片文件时，提示仅支持图片。

本地图片读取失败时，提示添加失败，不加入素材栈。

超过参考素材数量上限时，提示已达到上限。

参考素材路径在再次生成时不存在或不可访问时，提示该参考素材已失效，并允许用户移除后继续。

自定义尺寸不受支持时，提示最近可用尺寸，由用户确认后应用。

积分不足时不发起生成请求，按钮禁用并显示“积分不足”。

后端生成前重新校验尺寸、点数、参考素材权限和文件存在性。前端显示仅作体验提示，不能作为安全边界。

## 测试验收

首页测试需要以当前产品基准为准：

- 不再断言首页存在资产入口、后台入口或旧版图生图英雄文案。
- 未登录点击“开始创作”打开登录弹窗。
- 登录成功后仍留在首页并显示登录态。
- 登录后再次点击“开始创作”进入 `/workspace`。
- “充值”按钮保留当前跳转。

工作台测试需要覆盖：

- 输入区左侧存在加号素材入口。
- 可添加多张本地参考素材并叠放显示。
- 桌面 hover 展开，移动端点击展开。
- 点击缩略图打开放大预览。
- 可删除单张参考素材。
- 已生成图片可作为参考素材加入，不重复上传。
- 生成请求携带本地文件和已有图片路径。
- 再次生成/继续编辑记录时恢复 `reference_paths`。

计费测试需要覆盖：

- 最长边落入 1K / 2K / 4K 时按同档价格计费。
- 文生和带参考素材同档同价。
- 自定义宽高失焦后更新 `X 点`。
- 超出支持尺寸时推荐最近可用尺寸。
- 积分不足时按钮禁用，不发起生成请求。

资产测试需要覆盖：

- 删除资产后列表不再显示。
- 底层文件和历史引用仍保留。
- 引用被隐藏资产的历史记录仍可再次生成或继续编辑。

## 非目标

本轮不重构首页视觉，不改首页文案，不新增首页导航。

本轮不恢复旧的资产入口、后台入口、登录后自动进工作台。

本轮不做复杂在线支付，不新增团队空间，不做新的管理后台视觉改版。

本轮不把“参考图上传 / 图生图”作为显式用户入口。
