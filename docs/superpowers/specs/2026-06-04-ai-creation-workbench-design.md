# 绘世 AI 创作工作台需求设计

日期：2026-06-04

## 目标定位

绘世本轮定位为 AI 创作工作台，而不是单页图片生成器，也不是已经接入多媒体能力的综合创作平台。核心体验是把“创作、生成、保存、管理、再编辑”做成闭环。

本轮优先级采用 A 方案：

1. 先清理产品结构、路由、导航和权限。
2. 再打通工作台、资产库、资产详情之间的创作闭环。
3. 最后实现主题切换、高级筛选、批量操作、Prompt 优化等增强能力。

## 产品结构与路由

正式路由如下：

- `/workspace`：生成工作台。
- `/assets`：资产库，只展示图片资产。
- `/assets/<id>`：资产详情页。
- `/`：未登录用户看到首页；已登录用户自动进入 `/workspace`。

废弃 `/history`。它不再作为用户入口，也不再承载资产库页面。

导航规则：

- 普通用户显示：生成、资产、充值、账号、主题切换。
- 管理员额外显示：管理、设置。
- 不保留“灵感”入口。
- 不展示未接入的视频、音频、文档、无限画布等分类。
- 不使用“会员”文案，积分购买统一命名为“充值”。

现有 `/pricing` 可以继续作为充值页使用，但页面文案应统一为充值或积分充值。

## 工作台体验

工作台 `/workspace` 分为未生成前和生成后两种状态。

未生成前：

- 页面为极简创作入口。
- 中间显示欢迎或引导文案。
- 提供一个明显的大提示词输入框。
- 默认文生图，不展示复杂模式切换。
- 参考图上传作为入口；用户上传参考图后自动进入参考图生成逻辑。
- 参数默认收起，只露常用项：比例、清晰度、数量、参考图、生成按钮。
- 生成按钮附近显示预计消耗积分。

比例与清晰度：

- 比例包括 `1:1`、`16:9`、`9:16`、`3:2`、`2:3`。
- 清晰度包括 `1K`、`2K`、`4K`。
- 页面显示实际输出尺寸。
- 不支持的比例和清晰度组合应禁用。
- 预计消耗积分随模式、清晰度、数量变化。

生成中：

- 点击生成后，工作台立即出现生成任务卡片。
- 任务卡片显示 loading 状态、提示词摘要、参数摘要。
- 生成成功后替换为真实图片。
- 生成失败后保留失败卡片，显示失败原因，提供重试和重新编辑入口。
- 失败卡片不进入资产库，也不作为正式作品保存。

生成后：

- 页面展示“当前结果 + 最近作品”。
- 当前结果作为主视觉。
- 最近作品用于回看和切换。
- 当前结果操作包括：重新编辑、再次生成、查看参数、下载、收藏。

点数不足：

- 生成按钮仍可点击。
- 点击后如果积分不足，弹窗显示当前积分和预计消耗。
- 弹窗提供“去充值”入口。
- 不发起生成请求，不扣积分。

## Prompt 优化

工作台输入区提供 Prompt 优化能力。

交互规则：

- 提示词输入框旁提供“优化提示词”按钮。
- 优化按钮旁提供风格下拉。
- 风格包括：通用增强、写实摄影、插画二次元、商业设计、电影感、极简产品图。
- 用户点击优化后，前端调用真实 Prompt 优化接口。
- 弹窗展示原提示词和优化后的提示词。
- 用户点击“使用优化结果”后才替换输入框内容。
- Prompt 优化不自动触发图片生成。

接口与配置：

- 新增后端 Prompt 优化接口。
- 新增独立 Prompt 优化配置，不复用图片生成模型配置。
- 管理员在设置页配置 Prompt 优化 API Base URL、API Key、模型名。
- Prompt 优化配置为管理员全局配置，普通用户不接触 API Key。
- 如果管理员未配置，普通用户点击优化时显示“暂未启用 Prompt 优化”。

## 资产库

资产库 `/assets` 只展示图片资产。

布局规则：

- 采用网格优先布局，重点看图。
- 卡片默认主要展示图片。
- 卡片保留基础操作：收藏、更多。
- hover 时显示：再次编辑、下载、删除。
- 卡片不展示完整提示词、时间、参数。
- 完整信息进入资产详情页查看。

搜索和筛选：

- 顶部保持干净，包含搜索框、全部/收藏快捷入口、筛选按钮、批量操作入口。
- 搜索支持按提示词关键词搜索。
- 高级筛选通过弹层或抽屉打开。
- 筛选项包括：模式、时间、比例、清晰度、收藏状态。
- 支持组合筛选。
- 筛选结果为空时显示资产库空状态。

批量操作：

- 支持批量删除。
- 支持批量收藏和取消收藏。
- 支持批量下载。
- 批量下载使用 zip 打包。
- zip 文件名格式类似 `huishi-assets-日期.zip`。
- 单张删除和批量删除前都弹确认。
- 批量删除确认中显示选中数量。
- 暂不做软删除和撤销。

收藏规则：

- 单张卡片收藏即时切换。
- 详情页收藏即时切换。
- 批量模式支持批量收藏和取消收藏。
- 不做收藏夹或项目分组。

## 资产详情页

资产详情页使用独立路由 `/assets/<id>`。

页面内容：

- 主体展示大图预览。
- 展示完整信息：提示词、模式、比例、清晰度、尺寸、生成时间、消耗积分。
- 操作包括：再次编辑、再次生成、下载、收藏、删除。
- 返回入口回到 `/assets`。

再次编辑：

- 从资产库卡片或详情页点击再次编辑。
- 回到 `/workspace`。
- 自动带入原提示词和参数。
- 用户修改后再生成。

再次生成：

- 在详情页可直接使用原提示词和参数重新生成。
- 再次生成会扣除对应积分。
- 点击前弹出确认。
- 确认窗显示预计消耗积分。
- 确认窗提供“不再提示”。
- “不再提示”只保存在当前浏览器，不新增数据库字段。

## 主题

支持白色和黑色两种主题。

规则：

- 默认白色主题。
- 顶部导航右侧放一个图标按钮。
- 白色主题下显示暗色或月亮图标。
- 黑色主题下显示亮色或太阳图标。
- 点击图标在白色和黑色之间切换。
- 主题选择保存在当前浏览器，不新增数据库字段。

主题覆盖范围：

- `/workspace`
- `/assets`
- `/assets/<id>`
- 设置页中的工作台相关配置区域
- 参数弹层
- 筛选弹层
- 确认弹窗
- 生成中和失败卡片

首页、登录、注册、管理后台暂不跟随主题。

## 权限与设置

普通用户不需要设置页。

规则：

- 普通用户导航不显示“设置”。
- 普通用户直接访问设置页时提示无权限或跳转。
- 管理员可以看到“管理”和“设置”。
- 管理员在设置页配置图片生成 API 和 Prompt 优化 API。
- 普通用户只使用功能，不接触 API Key。

设置页新增“Prompt 优化”配置区，只对管理员可见。

## 实施阶段

第一阶段：产品结构先干净。

- 废弃 `/history`。
- 新增或改为 `/assets`。
- 新增或改为 `/assets/<id>`。
- 顶部导航改为生成、资产、充值、账号、主题切换。
- 管理员额外显示管理、设置。
- 删除灵感和未接入分类。
- 已登录用户访问 `/` 自动进入 `/workspace`。
- 普通用户不能访问设置页。

第二阶段：创作闭环。

- 资产库卡片支持再次编辑。
- 资产详情页支持再次编辑和再次生成。
- 再次编辑回到工作台并带入原提示词和参数。
- 再次生成弹确认并显示预计消耗积分。
- 支持不再提示。
- 工作台显示生成中任务卡片。
- 失败卡片保留，支持重试和重新编辑。
- 点数不足弹窗引导去充值。

第三阶段：增强功能。

- 白色和黑色主题切换。
- 资产库高级筛选弹层。
- 批量删除、批量收藏、批量取消收藏。
- 批量 zip 下载。
- Prompt 优化真实接口。
- Prompt 优化风格下拉和确认弹窗。
- 管理员设置页新增 Prompt 优化配置区。

## 验收标准

- `/assets` 能正常打开资产库。
- `/history` 不再作为页面入口。
- 普通用户导航没有设置、管理、灵感、会员字样。
- 导航显示“充值”。
- 资产卡片和详情页能回到工作台继续编辑。
- 再次生成不会误扣积分，必须确认。
- 点数不足不会发起生成。
- Prompt 优化未配置时有明确提示。
- 白色和黑色主题在工作台链路页面生效。
- 批量 zip 下载能下载所选图片。
- 自动化测试覆盖主要路由、权限、资产库、再次编辑、Prompt 优化配置。
- 浏览器验证桌面和移动端没有明显布局溢出。
