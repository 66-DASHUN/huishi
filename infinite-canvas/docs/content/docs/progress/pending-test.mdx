## 画布代理安全与结果稳定性

- 画布 API 仅接受可信画布 Origin，并优先使用 `X-Canvas-Session` 请求头传递短期会话令牌。
- 画布 iframe 初始化后会清除地址栏中的会话查询参数，消息通信绑定实际 iframe Origin。
- 画布生成张数默认 1 张，保留 1–10 张选项；旧节点继续显示并可修改已保存数量，费用预估与实际请求使用同一数量。批量结果由根图承载第 1 张，只创建剩余子图，不再多显示一张重复根图；Agent 每轮仍只触发一次生成任务。上游 URL 图片会安全下载到本地并按目标尺寸校正。
- PostgreSQL 启动迁移使用 advisory lock，避免 Gunicorn 多 worker 并发初始化死锁。
- 当前已通过 Python/Flask 全量测试 `379 passed, 60 skipped`、画布 Bun test 38 项、typecheck 与 production build；主站和画布服务已重启，桌面与移动 Playwright 截图已验证首页视频、工具栏居中、Agent 开关及后台配置页深浅主题。
